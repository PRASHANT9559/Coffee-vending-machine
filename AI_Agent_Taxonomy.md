## 6. MULTI-AGENT WORKFLOWS

### Core Orchestration Pattern (generic)
Manager Agent → Planner → Research Agent(s) → Data Agent → Analysis/Decision Agent → Drafting/Creation Agent → Execution Agent (computer-use) → Verification Agent → Reporting Agent → (loop to Manager)

### Workflow W1: Lead-to-Deal (Sales)
Lead Research → Lead Qualification → CRM Hygiene → Outreach Sequence → Meeting Scheduling → Proposal Drafting → Contract Review → Digital Signature → Customer Onboarding Agent
**Best for:** B2B sales, real estate, enterprise deals.

### Workflow W2: Procure-to-Pay
Supplier Portal → RFQ collection → Purchase Order creation → Three-Way Match → Invoice Processing → Approval routing → Payment execution (HITL) → Reconciliation → Spend Analysis
**Best for:** Manufacturing, retail, enterprise finance.

### Workflow W3: Hire-to-Onboard
Job posting → Resume Screening (HITL) → Candidate Comms → Interview Scheduling → Feedback collection → Offer → Employee Onboarding → Access Provisioning (HITL) → Payroll setup
**HITL gates:** All candidate decisions, access grants.

### Workflow W4: Order-to-Cash (E-commerce)
Listing Management → Order Processing → Inventory Monitor → Shipment Tracking → Review Management → Refund exceptions (HITL) → Reconciliation → Analytics
**Best for:** Amazon/Shopify sellers.

### Workflow W5: Incident Response (Security/IT)
System Monitoring → Incident Triage → SIEM Triage (HITL) → Threat Intel enrichment → Containment actions (HITL) → Phishing/vuln remediation tracking → Compliance Audit evidence → Executive report
**HITL gates:** Containment, customer comms.

### Workflow W6: Month-End Close (Finance)
Bookkeeping → Reconciliation → Invoice exceptions → Expense Audit → Payroll (HITL) → Financial Reporting → Variance analysis → Archive
**HITL gates:** Journal approvals, payroll, tax.

### Workflow W7: Content Engine (Marketing)
Keyword Research → Blog Writing → Editing → SEO optimization → Social Repurposing → Social Scheduling → Engagement handling (HITL) → Analytics → Iteration brief
**Best for:** media companies, D2C brands.

### Workflow W8: Grant Lifecycle (Nonprofit)
Grant discovery → Eligibility check (HITL) → Grant Writing → Compliance checklist → Digital Signature → Submission tracking → Fund accounting → Impact Reporting
**HITL gates:** Narrative, submission.

### Workflow W9: Regulatory Compliance Loop
Compliance Monitoring → Gap analysis → Policy draft updates (HITL) → Training assignment → Attestation tracking → Audit evidence collection → Regulatory Filing (HITL)
**Best for:** banking, energy, healthcare, gov contractors.

### Workflow W10: Launch Operations (Online Business)
Idea Validation → Funnel Building → Content creation → Email Marketing → Launch Campaign (HITL) → Webinar Ops → Order Processing → Feedback Analysis
**HITL gates:** Pricing, public sends.

**Multi-agent useful in:** Sales (W1), Finance (W2, W6), HR (W3), E-comm (W4), Sec/IT (W5), Marketing (W7), Nonprofit (W8), Regulated industries (W9), Launches (W10).

### Human-vs-AI classification rules (Phase 7)
- **Fully automatable:** deterministic rules, reversible actions, read-only monitoring, no external commitments (scheduling, monitoring, extraction, filing).
- **Mostly automatable:** drafts + routine execution, exceptions to humans (bookkeeping, tickets, listings).
- **AI-assisted:** AI produces, human decides (analysis, writing, research, design, proposals).
- **Human required:** judgment, accountability, legality, money movement, people's livelihoods (payroll, hiring decisions, medical, legal sign-off, tax filing).
- **Currently difficult/impractical:** deep physical-world ops, complex negotiation, novel creative direction, any task needing real-time accountability without a liable human.
